## LinkedIn / long-form social

Customer promises should behave like tests.

I built iPromise for Google's All Things Agentic Hackathon: a Taskmaster agent
that turns a supported privacy promise into a recurring control, tests an owned
synthetic product, and opens a verified draft PR when reality drifts from the
words customers were given.

Gemini 3.5 Flash + Google ADK + Cloud Run + Firestore + Cloud Build. The model
interprets language; deterministic controls own evidence, verdicts, and the
publication gate. One real PR, red-before/green-after proof, and duplicate-safe
reconciliation—without merge or deploy authority.

https://github.com/kostakarathana/iPromise
